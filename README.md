# FleetPilot Desktop — downloads

Installers for the FleetPilot desktop app. The platform itself lives at
https://fleet-pilot-kohl.vercel.app; this repository only hosts release files.

| Platform | Minimum | File |
|---|---|---|
| macOS, Apple silicon (M1 and later) | macOS 11 | `FleetPilot-<version>-mac-arm64.dmg` |
| macOS, Intel | macOS 10.13 High Sierra | `FleetPilot-<version>-mac-x64.dmg` |
| Windows 64-bit | Windows 7 SP1 · 8 · 8.1 · 10 · 11 | `FleetPilot-Setup-<version>-win-x64.exe` |
| Windows 32-bit | Windows 7 SP1 · 8 · 8.1 · 10 · 11 | `FleetPilot-Setup-<version>-win-ia32.exe` |

Get the latest version from the **Releases** page. The installers are not yet
code-signed: on macOS right-click the app and choose Open the first time; on
Windows choose "More info" → "Run anyway" on the SmartScreen prompt.
